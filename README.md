# AI Attendance Manager

## Prerequisites
- **Python 3.8+**
- **MongoDB**: You need to have MongoDB running locally on the default port (`localhost:27017`). If your database is hosted elsewhere, update the MongoDB URI string in `db.py`.

## Installation
1. Open a terminal in the project directory.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Run
1. Start the application by running:
   ```bash
   streamlit run app.py
   ```
2. Open the URL provided in your terminal (usually `http://localhost:8501`) in your web browser.
